vars
    := работает только внутри функции, за пределами функции объявлять переменную можно только через var

switch
    в go break не нужен

slices 
    слайс - это окно поверх массива

maps
    перед тем как писать в мапу - убедись, что она иницииализирована.

    при каждом запуске порядок может быть разный

    до го1.24 мапа была сделана из бакетов - ячеек фиксированного развмера (содержит до 8 ключей и значений), группирующих элементы с одинаковым хешем.
    начиная с го 1.24 - открытая адресация, швейцарские таблицы

    мапа не потокобезопасна.

pointers
    указатель - это адрес переменной в памяти.
    & - взять адрес
    * - прочитать значение по адресу

    перед разыменовыванием нужно проверить указатель на nil

    Go разыменовывает структуру при обращении к полям

    Возврат из функции указателя на локальную переменную безопасен

    При работе со слайсами и мапами указатель не нужен

advanced functions
    IIFE - Immediately Invoked Function Expression

    Замыкание - это анонимная функция, которая захватывает переменные из окружающего кода. Она получает указатель на переменнуб, а не копию.

    Callback - это функция, которую передаешь как аргумент в другую функцию, чтобы та вызвала ее позже.

errors
    ошибка в го это не какое-то там исключение, а просто значение, которое функция возвращает рядом с результатом.

error_hadnling
    defer - это отложенное выполнение
    panic - аварийная остановка обычного выполнения
    recover - это способ перехватить панику, но только по строгим правилам. Работает только внутри отложенной функции. 
    рековер работает только в той горутине, где произошла паника.

structures
    Структуры - группируют поля под одним именем.
    в Go есть инкапсуляция и методы, но отсутствует наследование и классический полиморфизм. Вместо базовых классов и подтипов Go предпочитает композицию и Dependency Injection.
    Dependency Injection - паттерн проектирования, при котором объект получает свои зависмости извне, а не создает их самостоятельно.
    Метод - это функция, которая связана с определенным типом через ресивер.
    Композиция - вместо наследования.
    Теги - это строки в кавычках после типа поля.
